# React Task Tracker App

A simple React-based task management app built as part of my internship at Flexisaf. This app helps users add and delete tasks dynamically using React's core concepts.

---

## Features

- Add new tasks
- Delete tasks
- Responsive and minimal design
- Clean and reusable component structure

---

## Built With

- [React](https://reactjs.org/)
- JavaScript (ES6+)
- JSX
- CSS
